原型 · v0 上下文骨架（一次红转绿任务）

把模型在一次「修复失败单测、红转绿」任务中实际看到的完整上下文逐轮摊开。点「推进一轮」或跑引导场景，观察上下文如何增长，以及稳定前缀与易变部分的边界落在哪里。

要回答的问题：完整上下文骨架如何组织？系统提示如何分段、工具定义摆在哪、`AGENTS.md` 注入在哪、失败观察如何回填、稳定前缀与易变部分的边界在哪。
假设：形态为一次性 CLI 任务 + 结构化工具调用，能力边界遵循 ADR 0001。工具细节见「工具契约」原型，此处只关心上下文的组织与流向。
