v0 工具契约：按按钮，看契约在哪里硌手

这份原型要回答的问题是：v0 的六种工具接口契约长什么样，以及在什么情况下会硌手？ 右侧是候选契约（JSON Schema、补丁格式、路径规则、截断策略、错误形态），左边是它的一个纯逻辑实现。 点「自由试」里的任意按钮可以直接戳模型；下面五个场景把难想清楚的边界情形排成了一条路。 每次操作后，状态面板都会显示完整的调用、结果和工作区，方便你说出「这里不该是这样」。
